## In-Class Notebook
EN: Create a blank notebook. **Put the project title and every group member’s name in the first Markdown cell.** Start with “Get the data” in the web tutorial.
JP: 空のNotebookを作ろう。**一番上のMarkdown Cellに、作品タイトルとグループ全員の氏名を必ず記入。** Webチュートリアルのデータ取得から始めよう。
## In-Class Challenge
EN: In groups of three, create a weather notebook using API data and a for loop. Show your results clearly, then demo them. **List every member in the notebook. Each member submits the same completed notebook separately to UNIPA.** [Instructions](weeks/week-07/challenge.html).
JP: 3人グループで、APIの天気データとforを使ったNotebookを作ろう。結果を分かりやすく表示し、最後に実演。**Notebookに全員の氏名を必ず記入し、同じ完成版を各メンバーがUNIPAへ提出。** [手順と教材](weeks/week-07/challenge.html)。
## Student Work
EN: Every team demos. Everyone speaks briefly and explains their for loop and results.
JP: 最後に全チームが実演。全員が一言話し、forと結果を説明する。
## Take-Home Assignment
EN: **Finish your group’s weather notebook.**

- **Required: put the project title and all three members’ names in the first Markdown cell.**
- Briefly describe what it does, the weather data source URL, your original features, and what you would improve next.
- Run all cells and save the outputs. Submit the `.ipynb` and any required files to UNIPA.

**Every member must submit separately—not just the group representative. All three submit the same completed version.**

**Deadline: Wednesday, November 18, 2026, 23:59 JST.**

JP: **グループで取り組んだ天気Notebookを完成させよう。**

- **必須：一番上のMarkdown Cellに、作品タイトルと3人全員の氏名を記入。**
- 何ができるNotebookか、天気データの出典URL、追加した機能・特徴、これから改善したいことを短く書く。
- 全Cellを実行し、結果を表示した状態で保存。`.ipynb`と実行に必要なファイルをUNIPAへ提出。

**代表者だけでなく、メンバー全員がそれぞれ提出してください。3人とも同じ完成版を提出します。**

**締切：2026年11月18日（水）23:59 JST。**
