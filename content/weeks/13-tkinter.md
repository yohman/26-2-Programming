## Lecture Flow
EN: 0–20: event-driven interfaces; 20–30: callbacks and input tests; 30–70: Tkinter/project notebook; 70–100: peer-use challenge.
JP: 0〜20分：イベント駆動インターフェース、20〜30分：コールバックと入力テスト、30〜70分：Tkinter／プロジェクトノートブック、70〜100分：ピア利用チャレンジ。
## In-Class Notebook
EN: **Week 13 In-Class — Interfaces and Project Implementation.** Write/trace a callback, have AI improve one validation message, then direct an agent through one bounded project issue and review its diff.
JP: **Week 13 In-Class — Interfaces and Project Implementation。** コールバックを書いて追跡し、AIで入力検証メッセージを一つ改善し、範囲を限定したプロジェクトissueでエージェントを導き差分をレビューする。
## In-Class Challenge
EN: Final 30 minutes: make a local app or project slice that one peer can use; record their test result.
JP: 最後の30分：仲間一人が使えるローカルアプリまたはプロジェクトの一部を作り、テスト結果を記録する。
## Take-Home Assignment
EN: Submit runnable files/repository, screenshot/video, peer test note, acceptance checklist, and workflow decision log.
JP: 実行可能なファイル／リポジトリ、スクリーンショット／動画、ピアテストメモ、受け入れチェックリスト、ワークフロー判断ログを提出。
## Aha!
EN: A button is not interaction until a tested function connects to it.
JP: ボタンはテスト済み関数につながるまで操作ではない。
## Takeaway
EN: Agent output needs a human user test.
JP: エージェント出力には人による利用テストが必要である。
