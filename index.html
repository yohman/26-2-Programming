THREE PROGRAMMING PRACTICES / 3つのプログラミング実践

01 / HUMAN CODING

Read. Trace. Write.

First understand the code yourself. Explain its state, write the essential part, and test your prediction.まず自分でコードを理解します。状態を説明し、必要な部分を書き、予想をテストします。

02 / AI COMPLETION

Extend. Debug. Check.

Use AI for a bounded next step—not a finished answer. Compare, test, and decide what to keep.完成品ではなく、限定した次の一歩にAIを使います。比べ、テストし、採用を判断します。

03 / AGENT-BASED CODING

Brief. Review. Verify.

Give an agent goals, context, constraints, and acceptance criteria. Review the change and prove it works.目標、文脈、制約、受け入れ基準をエージェントに渡します。変更をレビューし、動くことを証明します。

COURSE GUIDE / 授業について

Small pieces.
Real systems.

小さな部品から、本当に動く仕組みへ。

Programming is not a list of commands to memorize. It is a way to express an intention precisely enough that a computer can carry it out.プログラミングは、暗記する命令の一覧ではありません。コンピュータが実行できるほど正確に、自分の意図を表す方法です。

THE PURPOSE / この授業で

Make the computer useful.

コンピュータを役立つものにする。

Start with one line, then learn how small instructions become tools, stories, investigations, and projects of your own.

一行から始めて、小さな命令が自分の道具、ストーリー、調査、プロジェクトになるまでを学びます。

WHAT WE COVER / 学ぶこと

Values → logic → systems.

値 → 論理 → 仕組み。

You will work with values, input, data structures, choices, loops, functions, modules, interfaces, and real data—not as a vocabulary list, but as ways to make something happen.

値、入力、データ構造、選択、ループ、関数、モジュール、インターフェース、実データを扱います。用語の暗記ではなく、何かを起こすための道具として学びます。

HOW WE WORK / 授業の進め方

Learn → Try → Make.

学ぶ → 試す → つくる。

Each 100-minute class moves from a short lecture to a guided notebook, then a final 30-minute challenge. Take-home work turns that week’s idea into something personal.

100分の授業は、Short lecture、ガイド付きノートブック、最後の30分のチャレンジで進みます。持ち帰り課題では、その週の考えを自分のものにします。

ASSIGNMENT SUBMISSION / 課題の提出

Submit every take-home assignment through UNIPA.

すべての持ち帰り課題はUNIPAで提出します。

  1. Submit a fully working `.ipynb` notebook file.最後まで動く `.ipynb` ノートブックを提出する。
  2. Run the notebook from top to bottom before submitting so its output is visible.提出前に上から下まで実行し、出力が見える状態にする。
  3. Include the data, images, or other associated files your notebook needs.ノートブックが必要とするデータ、画像、その他の関連ファイルも含める。
  4. Complete the notebook with your own observations, notes, tests, and reflection.自分の観察、メモ、テスト、振り返りまでノートブックに残す。
