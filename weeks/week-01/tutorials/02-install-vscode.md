# Tutorial 02 — VS Codeを準備する

VS Codeはcodeを書く**作業机**です。Notebookに必要な二つのextensionだけを入れます。

> **GOAL / ゴール：** VS CodeにMicrosoft公式のPythonとJupyterが入っている。

## 1. VS Codeを入れる

1. [Visual Studio Code公式サイト](https://code.visualstudio.com/)から自分のOS用をdownloadする。
2. Windowsはinstallerを実行する。macOSはVS Codeを**Applications**へ移す。
3. VS Codeを起動する。

## 2. 二つのextensionを入れる

左側の**Extensions**を開き、次を検索して**Install**します。

| Extension | 役割 |
| --- | --- |
| **Python** | Pythonを選び、実行する |
| **Jupyter** | `.ipynb` Notebookを開く |

どちらも発行元が**Microsoft**であることを確認します。

> **TIP / ヒント：** ExtensionsはWindowsで`Ctrl + Shift + X`、macOSで`Command + Shift + X`でも開ける。

検索欄に`@installed`と入力し、PythonとJupyterが見えれば完了です。**Reload**が出たら押します。

> **CHECK / 確認：** VS Codeが起動し、`@installed`にMicrosoftのPythonとJupyterがある。
