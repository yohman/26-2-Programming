IDの「006」は、計算する6とは違うThe ID “006” has a different job from the number 6

文字列なら先頭の0を保てる。学籍番号や郵便番号も同じ。勝手に数値へ変えると、別データとの照合に失敗することがある。Strings preserve leading zeros, as student IDs and postal codes may need. Converting an ID to a number can break a match with another dataset.

Unix時刻は1970年1月1日00:00 UTCからの秒数。このフィードは整数で渡す。「いま取得した」と「いま報告された」は別。Unix time counts seconds since January 1, 1970, 00:00 UTC. This feed supplies an integer. Retrieval time and position-report time can differ.

辞書の中にリスト、その中に辞書A dictionary holding a list of dictionaries

feed = {
    "entity": [
        {"id": "D329", "vehicle": {
            "trip": {"route_id": "006"},
            "position": {"latitude": 35.659,
                         "longitude": 139.714}
        }}
    ]
}

実際の入れ子を、一台と必要なキーだけに省略。entityのリストには、同じ形の辞書が何台分も並ぶ。The real nesting, shortened to one vehicle and selected keys. The entity list holds more dictionaries with this structure.

大きなデータも、一段ずつOne level at a time

buses = feed["entity"]          # list
first = buses[0]                 # dict
vehicle = first["vehicle"]       # dict
position = vehicle["position"]   # dict
latitude = position["latitude"]  # float
Python
print(feed["entity"][0]["vehicle"]["position"]["latitude"])
35.659

[0]で順番を選ぶ。["キー"]で名前を選ぶ。長い式も、一段ずつなら読める。[0] chooses by position. ["key"] chooses by name. A long lookup follows these small steps.
