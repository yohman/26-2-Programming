リストと添字Lists and indexes

Python

print(playlist[-1])

あと一駅

The first index is 0; -1 selects the last item. An index identifies a position.

WEEK 03 · PART 2

追加も変更も、キーで指定Keys identify additions and changes

Python
scores = {"Math": 90, "English": 70}
scores["Programming"] = 65
scores["English"] = 80
del scores["Math"]
print(scores)
{'English': 80, 'Programming': 65}

存在しないキーへの代入は追加、既存のキーへの代入は変更。

Assigning a new key adds an entry. Assigning an existing key changes its value.

WEEK 03 · PART 2

KeyErrorにも手がかりがあるA KeyError gives you a clue

Python
profile = {"name": "Yuki", "year": 1}
print(profile["Name"])
KeyError: 'Name'

「name」と「Name」は違うキー。AIに聞く前に、辞書にあるキーと照合してみよう。修正は profile["name"]。

“name” and “Name” are different keys. Compare the lookup with the dictionary before asking for help. Fix: profile["name"].

WEEK 03 · PART 3

同じ構造で、自分のガイドYour guide uses the same structure

Python
guide = [
    {"name": "窓ぎわの席", "note": "朝は静か"},
    {"name": "木陰のベンチ", "note": "晴れた日に"}
]
for item in guide:
    print(f"{item['name']}：{item['note']}")
窓ぎわの席：朝は静か
木陰のベンチ：晴れた日に

地震でも勉強場所でも、一件ずつ取り出す仕組みは同じ。すべての辞書でキーをそろえると、同じコードを使える。

Earthquakes and study spots use the same record-by-record pattern. Consistent keys let the same code handle every item.
