① 相手の手を決める1. Choose the computer’s hand

import random

choices = ["グー", "チョキ", "パー"]
computer = random.choice(choices)
print(computer)

先週のlistから一つ選ぶ。random.choiceは実行するたびに選び直す。同じ手が続くこともある。random.choice picks one item from last week’s list. Repeated hands are possible.

② 入力を受け取る2. Read the player’s hand

player = input("グー・チョキ・パー：").strip()

if player not in choices:
    print("グー・チョキ・パーで入力してね。")

文字列のまま判定すれば、数字への変換エラーを避けられる。.strip()は前後の空白を取り除く。Keeping input as text avoids number-conversion errors. .strip() removes surrounding whitespace.

③ 同じ手なら、あいこ3. Same hand, a draw

if player not in choices:
    print("入力を確認してね")
elif player == computer:
    print("あいこ！")

入力の確認を先にする。正しい入力なら、次は同じ手か調べる。Validate first. For a valid hand, check whether the two hands match.

④ 勝つ組み合わせ4. Winning combinations

elif (
    (player == "グー" and computer == "チョキ")
    or (player == "チョキ" and computer == "パー")
    or (player == "パー" and computer == "グー")
):
    print("あなたの勝ち！")
else:
    print("コンピュータの勝ち！")

一つの勝ち方はand、三つの勝ち方をorでつなぐ。残る正しい入力は負け。Each winning pair uses and. The three pairs connect with or. Remaining valid pairs lose.

じゃんけんの全体The complete game

import random
choices = ["グー", "チョキ", "パー"]
computer = random.choice(choices)
player = input("グー・チョキ・パー：").strip()
print(f"相手の手：{computer}")

if player not in choices:
    print("入力を確認してね")
elif player == computer:
    print("あいこ！")
elif (
    (player == "グー" and computer == "チョキ")
    or (player == "チョキ" and computer == "パー")
    or (player == "パー" and computer == "グー")
):
    print("あなたの勝ち！")
else:
    print("コンピュータの勝ち！")
