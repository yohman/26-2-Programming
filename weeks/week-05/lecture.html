RANGE / 数をつくる

range(1, 5) は 1 から 4means 1 through 4

Python
for count in range(1, 5):
    print("{} sheep".format(count))
print("Good night")
1 sheep
2 sheep
3 sheep
4 sheep
Good night

range(start, end)はendの手前まで。range(5)なら0〜4。.format(count)は{}に値を入れる。f"{count} sheep"とも書ける。range(start, end) stops before end. range(5) gives 0–4. .format(count) fills {} with a value. f"{count} sheep" is equivalent.

SQUARES + TOTAL / 例5

2乗してから、合計に足すSquare each value, then add it

Python
total = 0
for num in range(1, 11):
    total += num ** 2
print(total)
385

** 2は2乗。+=で今の合計に足す。range(1, 4)なら 1 + 4 + 9 = 14。** 2 means squared. += adds to the current total. With range(1, 4), the result is 1 + 4 + 9 = 14.

APPEND / 数から新しいリスト

2乗した値を、一つずつ保存するSave the squared values in a new list

Python
values = [1, 2, 3, 4, 5]
squares = []
for value in values:
    squares.append(value ** 2)
print(squares)
[1, 4, 9, 16, 25]

total += ...は合計を一つ作る。append()は結果を一件ずつ残す。squares = []をループの中に入れたら？total += ... produces one total. append() keeps each result. What if squares = [] moves inside the loop?

FILTER / 必要な値だけ残す

if と append() を、ループの中に置くPut if and append() inside the loop

Python
scores = [43, 61, 78, 55, 92]
passing = []

for score in scores:
    if score >= 60:
        passing.append(score)

print(passing)
[61, 78, 92]

if が通った値だけを、新しいリスト passing に追加する。append() の字下げ位置が大切。Only values that pass the if go into the new passing list. The indentation of append() matters.

FOR LOOP / DATAFRAME

全都道府県の人口を、一行ずつ合計するAdd every prefecture’s population, one row at a time

Python
total_population = 0

for index, row in df.iterrows():
    total_population += row["総人口"]

print(f"このデータの総人口: {total_population:,} 人")
このデータの総人口: 124,946,000 人

iterrows() は一行ずつの記録を渡す。index はここでは使わない行番号、row は一都道府県のデータ。iterrows() gives one record at a time. index is the unused row number here, and row holds one prefecture’s data.
