LIST / 配列のように順番を持つ値

snacks = ["おにぎり", "ラーメン", "カレー"]

print(snacks[0])

Pythonでは [ ] を使った順番のある集まりを list と呼ぶ。配列のように、値を一つずつ取り出せる。In Python, an ordered group inside [ ] is a list. Like an array, we can take one value at a time.

FOR LOOP / 01

for で、一つずつ名前を受け取るtakes each name, one at a time

Python
names = ["Aoi", "Kai", "Mina"]

for name in names:
    print(f"Welcome, {name}!")
Welcome, Aoi!
Welcome, Kai!
Welcome, Mina!

RANGE / 数をつくる

range(1, 5) は 1 から 4means 1 through 4

Python
for number in range(1, 5):
    print(f"Round {number}")
Round 1
Round 2
Round 3
Round 4

range(start, end) は endの手前まで。range(5) なら 0, 1, 2, 3, 4。range(start, end) stops before end. range(5) gives 0, 1, 2, 3, 4.

FILTER / 必要な値だけ残す

if と append() を、ループの中に置くPut if and append() inside the loop

Python
scores = [43, 61, 78, 55, 92]
passing = []

for score in scores:
    if score >= 60:
        passing.append(score)

print(passing)
[61, 78, 92]

if が通った値だけを、新しいリスト passing に追加する。append() の字下げ位置が大切。Only values that pass the if go into the new passing list. The indentation of append() matters.

MAKE A RESULT / 結果を増やす

一つの名前から、一つのラベルをつくるMake one label from each name

Python
names = ["Aoi", "Kai", "Mina"]
badges = []

for name in names:
    badge = f"★ {name}"
    badges.append(badge)

print(badges)
['★ Aoi', '★ Kai', '★ Mina']

リストに4人いたら、badges には何個の文字列が入る？If the list holds four people, how many strings end up in badges?

DATA / 1行が1件の記録

データでも、同じループを使えるData uses the same loop

Python
prefectures = [
    {"name": "北海道", "population": 5_140_000},
    {"name": "東京都", "population": 14_038_000},
    {"name": "大阪府", "population": 8_782_000},
]

for prefecture in prefectures:
    name = prefecture["name"]
    population = prefecture["population"]
    print(f"{name}: {population:,} people")
北海道: 5,140,000 people
東京都: 14,038,000 people
大阪府: 8,782,000 people

リストの各要素が一都道府県の記録。ループは一件ずつ、同じラベルをつくる。あとで japan.csv の全行に広げる。Each list item is one prefecture record. The loop makes the same label for each record. Soon, extend this to every row in japan.csv.
