Bの人は、Cellの種類をCodeにして下のコードをコピーし、Shift + Enterで実行してください。csvはPythonに標準で入っているため、pandasも追加インストールも不要です。 Aの人は、すでに動いている読み込み方法で構いません。Route B: choose a Code cell, copy the code below, and press Shift+Enter. csv is included with Python; no pandas or extra installation is needed. import csv

with open("japan.csv", encoding="utf-8-sig", newline="") as file:
    data = list(csv.DictReader(file))

print(len(data))

結果：Result: 47

DictReader は列名で値を取り出せるようにします。data は47都道府県の記録を並べたリストです。DictReader lets you access values by column name. data is a list of 47 prefecture records.

4. 計算する値は、数値にするConvert values before calculating

標準のcsvで読み込んだ値は文字列です。人数は int()、小数を含む値は float() で数値にします。Values loaded by csv are strings. Use int() for whole numbers and float() for decimals.

row = data[0]
population = int(row["総人口"])
seniors = int(row["65歳以上人口"])
share = seniors / population * 100
print(row["都道府県"], round(share, 1), "%")
北海道 32.8 %

これは最初の都道府県の高齢者割合を計算した例です。ここから、依頼に合う指標と比較対象を選びましょう。This calculates the older-population share for the first prefecture. Now choose measures and comparisons that fit your brief.

人数が多いことと、割合が高いことは別です。何を比較するかで、適切な指標を選んでください。A large count and a high share answer different questions. Choose the measure that fits your comparison.
