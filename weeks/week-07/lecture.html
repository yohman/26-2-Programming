WEEK 07 · ¥1,000 after class
for と whilefor and while
forはリストの各要素を調べる。whileは条件がTrueの間続く。どちらも状態の変化を追う。for visits items; while continues while a condition is true. Trace the changing state.
Python
coins = [100, 30, 50]
paid = 0
for coin in coins:
    if coin in [10, 50, 100]:
        paid += coin
print(paid)

予算内の候補Which options fit?
<=は「以下」。150円の予算なら、150円の商品も含める。<= includes an item that costs exactly the budget.
Python
budget = 500
for item in menu:
    if item["price"] <= budget:
        print(item["name"], item["price"])
