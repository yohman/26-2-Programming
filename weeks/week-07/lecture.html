WEEK 07 · WEATHER HACKATHON

APIから予報をもらうGet the forecast from an API

urlopenで受け取り、json.loadで辞書にする。最後のlen(...)は取得した時間数。Notebookではセルの最後の値が、そのまま表示される。urlopen gets the response; json.load reads it into a dictionary. The final len(...) counts forecast hours. A notebook displays the last value automatically.

Python
import json
from urllib.request import urlopen
from urllib.parse import urlencode

url = "https://api.open-meteo.com/v1/forecast?" + urlencode({
    "latitude": 35.86, "longitude": 139.97,
    "hourly": "temperature_2m,precipitation_probability",
    "forecast_hours": 24, "timezone": "Asia/Tokyo"
})
with urlopen(url, timeout=10) as response:
    data = json.load(response)
len(data["hourly"]["time"])
24

実際のAPI実行結果：2026-11-12 00:23 JST取得、柏の24時間予報。Open-Meteo APIドキュメント。今取得すると数値や時刻は変わります。Actual API run: Kashiwa, retrieved 2026-11-12 00:23 JST. Open-Meteo API docs. A fresh request will return different times or values.

WEEK 07 · WEATHER HACKATHON

1時間を、一つの辞書にOne hour, one dictionary

同じ番号iで、時刻・気温・降水確率を組にする。forecastは辞書のリスト。Use the same index i to pair the time, temperature and rain probability. forecast is a list of dictionaries.

Python
forecast = []
hourly = data["hourly"]
for i in range(len(hourly["time"])):
    temp = hourly["temperature_2m"][i]
    rain = hourly["precipitation_probability"][i]
    if temp is not None and rain is not None:
        forecast.append({"time": hourly["time"][i],
                         "temp": temp, "rain": rain})
forecast[0]
{'time': '2026-11-12T00:00', 'temp': 9.8, 'rain': 0}

time＝日本時間、temp＝°C、rain＝降水確率%。None（値なし）の時間は除く。time = Japan time; temp = °C; rain = probability %. Skip hours with missing values (None).
