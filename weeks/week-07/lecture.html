  • 「明日、どこで雨が降りそう？」→ 選んだ複数の街をforで比較する。“Where might it rain tomorrow?” Use for to compare a chosen list of cities.

01 データ取得を開くOpen Tutorial 01: Get the data ↗
  1. 設定する：lat / lonは場所、past_days / forecast_daysは期間、daily_fieldsは欲しい項目。Set the inputs: lat / lon choose the place, day counts set the period, and daily_fields selects the weather fields.

  3. 読む：weather["daily"]には、日付・気温・降水確率・雨量のリストが入っている。Read the result: weather["daily"] contains lists of dates, temperatures, precipitation probabilities and rainfall.

初期設定は過去1日＋今日を含む予報3日＝4日分。同じ番号iの日付と数値が対応します。Defaults: 1 past day + 3 forecast days including today = 4 dates. The same index i matches a date with its values.

設定を、先に決めるSet the parameters first

緯度・経度、日数、欲しい項目を変数にする。変更はここから。Set the coordinates, day counts and weather fields first. This is where you make changes.

Python
# ① 取得する場所と期間を設定する（柏市の例）

# 緯度
lat = 35.86224

# 経度
lon = 139.97733

# 過去何日分を含めるか
past_days = 1

# 今日を含む予報の日数
forecast_days = 3

# 取得する場所の現地時間を使う
timezone = "auto"

# 欲しい天気の項目を、カンマ区切りの文字列で指定する
daily_fields = (
    "temperature_2m_max,temperature_2m_min,"
    "precipitation_probability_max,rain_sum,showers_sum"
)

# 通信を待つ最大秒数
timeout = 10

lat / lon＝場所。past_days＝過去の日数。forecast_days＝今日を含む予報の日数。設定を変えたら、次のAPIセルも再実行。lat / lon choose the place. past_days adds past dates; forecast_days includes today. After changing a setting, rerun the API cell too.

設定を使って、APIへUse the settings to request data

前の設定をURLのパラメータに渡す。urlopenで接続し、json.loadで辞書に読む。Pass the settings into the URL parameters. urlopen connects; json.load reads the response into a dictionary.

Python
# 通信とJSONの読み取りに使う標準ライブラリ
import json
from urllib.request import urlopen
from urllib.parse import urlencode

# ② 設定した変数をパラメータに渡し、URLを作る
url = "https://api.open-meteo.com/v1/forecast?" + urlencode({
    "latitude": lat, "longitude": lon,
    "daily": daily_fields,
    "past_days": past_days, "forecast_days": forecast_days,
    "timezone": timezone
})

# ③ APIから取得したJSONを、Pythonの辞書に変換する
with urlopen(url, timeout=timeout) as response:
    weather = json.load(response)

# ④ 日別データを表示する（セルの最後の値はprint不要）
weather["daily"]

forで、日ごとに取り出すUse for to read each day

start_dayで開始日を選ぶ。past_daysを足すと、設定に合わせて今日・明日の番号になる。Choose where to start with start_day. Adding past_days keeps the date index aligned with your request settings.

Python
# ① 何日目から表示するかを選ぶ（0＝今日、1＝明日）
start_day = 0

# ② 過去の日数を足し、指定した日から1日ずつ取り出す
daily = weather["daily"]
for i in range(past_days + start_day, len(daily["time"])):

    # 同じ番号iを使うと、日付と天気の値が対応する
    print(daily["time"][i],
          daily["temperature_2m_max"][i], "°C",
          daily["precipitation_probability_max"][i], "%")
2026-11-12 17.4 °C 0 %
2026-11-13 19.4 °C 0 %
2026-11-14 20.0 °C 4 %

0＝今日から、1＝明日から。同じ番号iで日付・気温・降水確率を取り出す。0 starts today; 1 starts tomorrow. Use the same index i for the date, temperature and precipitation probability.
