Open-Meteoのデータ取得Get data from Open-Meteo

先にlat・lon・past_days・forecast_daysなどの設定を決め、Code Cellで実行します。設定を変えたらこのセルを再実行。urlopenで接続し、json.loadでJSONをPythonの辞書に読み込みます。Set lat, lon, day counts and other inputs up front, then run the cell. After changing a setting, rerun this cell to fetch matching data. json.load turns the JSON response into a Python dictionary.

# 通信とJSONの読み取りに使う標準ライブラリ
import json
from urllib.request import urlopen
from urllib.parse import urlencode

# ① 取得する場所と期間を設定する（柏市の例）

# 緯度
lat = 35.86224

# 経度
lon = 139.97733

# 過去何日分を含めるか
past_days = 1

# 今日を含む予報の日数
forecast_days = 3

# 取得する場所の現地時間を使う
timezone = "auto"

# 欲しい天気の項目を、カンマ区切りの文字列で指定する
daily_fields = (
    "temperature_2m_max,temperature_2m_min,"
    "precipitation_probability_max,rain_sum,showers_sum"
)

# 通信を待つ最大秒数
timeout = 10

# ② 設定した変数をパラメータに渡し、URLを作る
url = "https://api.open-meteo.com/v1/forecast?" + urlencode({
    "latitude": lat, "longitude": lon,
    "daily": daily_fields,
    "past_days": past_days, "forecast_days": forecast_days,
    "timezone": timezone
})

# ③ APIから取得したJSONを、Pythonの辞書に変換する
with urlopen(url, timeout=timeout) as response:
    weather = json.load(response)

# ④ 日別データを表示する（セルの最後の値はprint不要）
weather["daily"]

① 都市名から場所を探す① Find the city

都市名・候補数・言語・待ち時間を先に設定し、最初の候補results[0]の地域・国を確認。Set the city, match count, language and timeout first, then check the first match’s region and country.

# 通信とJSONの読み取りに使う標準ライブラリ
import json
from urllib.request import urlopen
from urllib.parse import urlencode

# ① 調べたい都市名と検索条件を設定する

# 別の都市名に変えてみよう
city = "Kashiwa"

# 取得する候補の数
match_count = 1

# 地名の表示言語

# 通信を待つ最大秒数
timeout = 10

# ② 都市名を検索用のURLに入れ、場所の情報を取得する
url = "https://geocoding-api.open-meteo.com/v1/search?" + urlencode({

# ③ 最初の候補を選び、都市・地域・国が合っているか確認する

今日、雨は？Rain today

先に データ取得 を実行。Run Get the data first.

day_offsetとumbrella_thresholdを先に決める。i = past_days + day_offsetで日付の番号を計算。ifで表示を変える。50%はこの例の目安なので、自分たちの目的に合わせて変えよう。降水確率は降る時間の割合ではなく、雪も含みます。雪が予想される場所では雨量も確認。Set the day offset and umbrella threshold first; add past_days to find the matching date. The 50% umbrella rule is our choice, not an API recommendation. Probability is not the fraction of the day it will rain. It includes snow; check the rain amount too in snowy weather.

# ① 調べる日と、傘を勧める基準を決める

# 0＝今日、1＝明日
day_offset = 0

# 降水確率の基準（%）
umbrella_threshold = 50

# ② 対象の日の降水確率を取り出す
daily = weather["daily"]
i = past_days + day_offset
chance = daily["precipitation_probability_max"][i]
print(daily["time"][i])

# Noneはデータなし。0%とは区別する
if chance is None:
    print("Rain probability is unavailable.")
else:
    print("Maximum precipitation probability:", chance, "%")

    # ③ 自分たちで決めた基準と比べ、メッセージを変える
    if chance >= umbrella_threshold:
        print("An umbrella may be useful.")
    else:
        print("A lower rain chance, but not a guarantee.")

昨日、雨だった？Yesterday’s rain

先に データ取得 を実行。Run Get the data first.

day_offset = -1で昨日を選ぶ。past_daysは1以上必要。rain_sum + showers_sumで液体の雨量（mm）。Noneはデータなし。0と区別しよう。昨日の値は過去予報のモデル推定で、実際の雨を確認する観測記録ではありません。Set day_offset to -1 and request at least one past day. Add rain and showers in mm. These past-day model values are not confirmed station observations.

# ① 昨日を選ぶ（取得セルのpast_daysは1以上にする）

# -1＝昨日、0＝今日
day_offset = -1

# ② 日付の番号を計算し、2種類の雨量を取り出す（mm）
daily = weather["daily"]
i = past_days + day_offset
rain = daily["rain_sum"][i]
showers = daily["showers_sum"][i]
print(daily["time"][i])

# どちらかの値がないときは、合計を計算しない
if rain is None or showers is None:
    print("Rainfall estimate is unavailable.")
else:

    # ③ 雨量を合計する。昨日の値は観測ではなくモデルの推定
    amount = rain + showers
    print("Model-estimated rainfall:", amount, "mm")
    if amount > 0:
        print("The model suggests some rain.")
    else:
        print("The model estimates no rain.")

日ごとにforLoop over days

先に データ取得 を実行。Run Get the data first.

start_dayで開始日を指定。0は今日、1は明日。past_days + start_dayから、取得した最後の日まで読む。同じ番号iのデータを組にする。print()はループ内の各行の表示に必要です。Set start_day first, then pair each date with the values at the same index.

# ① 表示を始める日を選ぶ（0＝今日、1＝明日）

# ② 指定した日から、取得済みの最後の日まで繰り返す

          daily["temperature_2m_max"][i], "°C |",
          daily["precipitation_probability_max"][i], "%")

街を比べるCompare cities

先に データ取得 を実行。Run Get the data first.

選んだ3都市の「明日の降水確率」をforで比べる。countryCode="JP"は日本の街に限定。cities・国・日数を最初に設定。day_offset = 1で明日を選び、i = past_days + day_offsetで番号を計算。各地の現地日付を表示します。Compare the chosen cities, not every place in the world. Choose the cities, country and day settings first. day_offset = 1 selects tomorrow; its index is past_days + day_offset. The displayed date is local to each city.

# ① 比べる都市と、APIの取得条件を先に設定する
cities = ["Tokyo", "Osaka", "Naha"]

# 日本の都市に絞る
country_code = "JP"

# 地名の表示言語
language = "en"

# 各都市の検索候補数
match_count = 1

# 過去何日分を含めるか
past_days = 1

# 今日を含む取得日数
forecast_days = 3

# 各都市の現地時間
timezone = "auto"
daily_fields = "precipitation_probability_max"

# 0＝今日、1＝明日
day_offset = 1

# 通信を待つ最大秒数
timeout = 10

# ② 都市ごとに「場所の検索→天気の取得→表示」を繰り返す
for city in cities:

    # 都市名から、最初の候補の場所を調べる
    url = "https://geocoding-api.open-meteo.com/v1/search?" + urlencode({
        "name": city, "count": match_count,
        "language": language, "countryCode": country_code
    })
    with urlopen(url, timeout=timeout) as response:
        city_place = json.load(response)["results"][0]

    # 見つかった緯度・経度を、天気APIに渡す
    lat = city_place["latitude"]
    lon = city_place["longitude"]
    url = "https://api.open-meteo.com/v1/forecast?" + urlencode({
        "latitude": lat, "longitude": lon, "daily": daily_fields,
        "past_days": past_days, "forecast_days": forecast_days,
        "timezone": timezone
    })
    with urlopen(url, timeout=timeout) as response:
        city_weather = json.load(response)

    # ③ 指定した日の日付と降水確率を表示する
    daily = city_weather["daily"]
    i = past_days + day_offset
    chance = daily["precipitation_probability_max"][i]
    print(city_place["name"], daily["time"][i], chance, "%")

見える予報A visual forecast

先に データ取得 を実行。Run Get the data first.

文字の棒なら追加ライブラリ不要。bar_widthは正の整数にし、記号も最初に決める。filled * blocksで文字を繰り返し、round()で棒の長さを丸める。{chance:3}は3文字分の幅で数字をそろえる。数値も一緒に出して丸めた量を明確に。Repeat a character to make a bar. Set a positive bar_width and choose the symbols first. With width 20, each block represents about five percentage points; keep the exact percentage beside it.

# ① 表示する日と、文字の棒の見た目を決める

# 0＝今日から、1＝明日から
start_day = 0

# 棒全体の文字数（正の整数）
bar_width = 20

# 確率に応じて塗る部分
filled = "█"

# 残りの部分
empty = "░"

# ② 100%を棒の長さで割り、1文字分の割合を求める
daily = weather["daily"]
points_per_block = 100 / bar_width
print("Maximum precipitation probability")
print("Each block is about", points_per_block, "percentage points.")

# ③ 各日の降水確率を、文字の棒で表示する
for i in range(past_days + start_day, len(daily["time"])):
    chance = daily["precipitation_probability_max"][i]
    if chance is None:
        print(daily["time"][i], "No data")
    else:

        # 文字数を丸め、塗る部分と残りの部分をつなぐ
        blocks = round(chance / points_per_block)
        bar = filled * blocks + empty * (bar_width - blocks)

        # 丸める前の正確な%も、棒の横に表示する
        print(f'{daily["time"][i]} |{bar}| {chance:3}%')

任意：whileOptional while

先に データ取得 を実行。Run Get the data first.

day_optionsとquit_commandを最初に設定。新しい通信はせず、取得済みのデータを繰り返し見る例。入力をループの最後で更新し、qで終了。コード集の出力例では入力を0 → 1 → qとしています。必須ではありません。Reuse the loaded weather and update the choice each time. Set the allowed days and quit command first. Sample inputs: 0, 1, q. This extension is optional.

# ① 選べる日と、終了用の入力を決める

# 0＝今日、1＝明日
day_options = ["0", "1"]

# この文字を入力したら終了
quit_command = "q"
prompt = f"Days ahead {day_options}, {quit_command} = quit: "

# ② 取得済みのデータを使い、最初の入力を受け取る
daily = weather["daily"]
choice = input(prompt)

# ③ 終了コマンドが入力されるまで繰り返す
while choice != quit_command:
    if choice in day_options:

        # 入力は文字列なので、計算する前にintで整数にする
        i = past_days + int(choice)
        print(daily["time"][i],
              daily["temperature_2m_max"][i], "°C")
    else:
        print("Choose from", day_options, "or", quit_command)

    # 入力を更新し、次のwhileの条件で確かめる
    choice = input(prompt)
