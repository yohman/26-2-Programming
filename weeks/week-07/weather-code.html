Open-Meteoのデータ取得 / Get the data

自分のNotebookのCode Cellで実行。柏の緯度・経度を指定し、Open-Meteoへ1回リクエストします。urlopenで接続し、json.loadでJSONをPythonの辞書に読み込みます。
Run this in your own notebook. One request gets weather for Kashiwa’s coordinates. json.load turns the JSON response into a Python dictionary.

import json
from urllib.request import urlopen
from urllib.parse import urlencode

# Kashiwa, Japan
url = "https://api.open-meteo.com/v1/forecast?" + urlencode({
    "latitude": 35.86224, "longitude": 139.97733,
    "daily": ("temperature_2m_max,temperature_2m_min,"
              "precipitation_probability_max,rain_sum,showers_sum"),
    "past_days": 1, "forecast_days": 3, "timezone": "auto"
})
with urlopen(url, timeout=10) as response:
    weather = json.load(response)
weather["daily"]

APIの応答には位置・単位・天気データが含まれます。ここでは最後のweather["daily"]で、日別データの部分を表示しています。各項目は、同じ日付順に並んだリストです。
The response contains location, units and weather data. The final expression shows its daily data: one list for each field, aligned by date.

この設定では 0＝昨日、1＝今日、2＝明日、3＝明後日。
temperature_2m_max / min＝最高・最低気温（°C）。precipitation_probability_max＝最大降水確率（%）。rain_sum + showers_sum＝雨量（mm）。
With these settings: 0 yesterday, 1 today, 2 tomorrow, 3 the next day. Dates use the location’s local time. Yesterday’s rainfall is model-estimated; probability is not certainty.

① 都市名 → 場所 / Find the city

cityを書き換え、最初の候補results[0]の地域・国を確認。 / Edit city and check the first match’s region and country.

import json
from urllib.request import urlopen
from urllib.parse import urlencode

city = "Kashiwa"  # Change this city name
url = "https://geocoding-api.open-meteo.com/v1/search?" + urlencode({
    "name": city, "count": 1, "language": "en"
})
with urlopen(url, timeout=10) as response:
    locations = json.load(response)
place = locations["results"][0]
place["name"], place.get("admin1"), place["country"]

今日、雨は？ / Rain today

先に データ取得 を実行。 / Run Get the data first.

i = 1は最初の例で取得した「今日」。ifで表示を変える。50%はこの例の目安なので、自分たちの目的に合わせて変えよう。降水確率は降る時間の割合ではなく、雪も含みます。雪が予想される場所では雨量も確認。 / Index 1 is today in the first example. The 50% umbrella rule is our choice, not an API recommendation. Probability is not the fraction of the day it will rain. It includes snow; check the rain amount too in snowy weather.

daily = weather["daily"]
i = 1  # Today with the first example’s settings
chance = daily["precipitation_probability_max"][i]
print(daily["time"][i])
if chance is None:
    print("Rain probability is unavailable.")
else:
    print("Maximum precipitation probability:", chance, "%")
    if chance >= 50:
        print("An umbrella may be useful.")
    else:
        print("A lower rain chance, but not a guarantee.")

昨日、雨だった？ / Yesterday’s rain

先に データ取得 を実行。 / Run Get the data first.

rain_sum + showers_sumで液体の雨量（mm）。Noneはデータなし。0と区別しよう。昨日の値は過去予報のモデル推定で、実際の雨を確認する観測記録ではありません。 / Add rain and showers in mm. These past-day model values are not confirmed station observations.

daily = weather["daily"]
i = 0  # Yesterday with past_days = 1
rain = daily["rain_sum"][i]
showers = daily["showers_sum"][i]
print(daily["time"][i])
if rain is None or showers is None:
    print("Rainfall estimate is unavailable.")
else:
    amount = rain + showers
    print("Model-estimated rainfall:", amount, "mm")
    if amount > 0:
        print("The model suggests some rain.")
    else:
        print("The model estimates no rain.")

06 / PYTHON → OUTPUT

街を比べる / Compare cities

先に データ取得 を実行。 / Run Get the data first.

選んだ3都市の「明日の降水確率」をforで比べる。countryCode="JP"は日本の街に限定。最初の例と同じ設定なので2＝明日。各地の現地日付を表示します。 / Compare the chosen cities, not every place in the world. The first example’s date indexes still apply: 2 is tomorrow. The displayed date is local to each city.

cities = ["Tokyo", "Osaka", "Naha"]
for city in cities:
    url = "https://geocoding-api.open-meteo.com/v1/search?" + urlencode({
        "name": city, "count": 1, "language": "en", "countryCode": "JP"
    })
    with urlopen(url, timeout=10) as response:
        city_place = json.load(response)["results"][0]

    url = "https://api.open-meteo.com/v1/forecast?" + urlencode({
        "latitude": city_place["latitude"],
        "longitude": city_place["longitude"],
        "daily": "precipitation_probability_max",
        "past_days": 1, "forecast_days": 3, "timezone": "auto"
    })
    with urlopen(url, timeout=10) as response:
        city_weather = json.load(response)

    # Same settings as the first example: 2 = tomorrow
    tomorrow = city_weather["daily"]
    chance = tomorrow["precipitation_probability_max"][2]
    print(city_place["name"], tomorrow["time"][2], chance, "%")

07 / PYTHON → OUTPUT

見える予報 / A visual forecast

先に データ取得 を実行。 / Run Get the data first.

文字の棒なら追加ライブラリ不要。"█" * blocksで文字を繰り返し、round()で棒の長さを丸める。{chance:3}は3文字分の幅で数字をそろえる。数値も一緒に出して丸めた量を明確に。 / Repeat a character to make a bar. Each block represents about five percentage points; keep the exact percentage beside it.

daily = weather["daily"]
print("Maximum precipitation probability")
print("Each block is about 5 percentage points.")
for i in range(1, len(daily["time"])):
    chance = daily["precipitation_probability_max"][i]
    if chance is None:
        print(daily["time"][i], "No data")
    else:
        blocks = round(chance / 5)
        bar = "█" * blocks + "░" * (20 - blocks)
        print(f'{daily["time"][i]} |{bar}| {chance:3}%')

任意：while / Optional while

先に データ取得 を実行。 / Run Get the data first.

新しい通信はせず、取得済みのデータを繰り返し見る例。入力をループの最後で更新し、qで終了。コード集の出力例では入力を1 → 2 → qとしています。必須ではありません。 / Reuse the loaded weather and update the choice each time. Sample inputs: 1, 2, q. This extension is optional.

daily = weather["daily"]
choice = input("1 = today, 2 = tomorrow, q = quit: ")
while choice != "q":
    if choice in ["1", "2"]:
        i = int(choice)
        print(daily["time"][i],
              daily["temperature_2m_max"][i], "°C")
    else:
        print("Please enter 1, 2 or q.")
    choice = input("1 = today, 2 = tomorrow, q = quit: ")

PYTHON OUTPUT / 実行結果

2026-11-12 17.4 °C
2026-11-13 19.4 °C
