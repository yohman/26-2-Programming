友だちの条件でも使える？Make it work for a friend

予算ツールを、友だちが条件を変えて使えるようにする。先週の提出がなくても、今日のスターターから始められる。自転車盗データの集計は選択課題。Make a budget tool a friend can use with different settings. Start with today’s notebook even without last week’s work. Bicycle-theft counting is an alternative challenge.

まず、ここからStart here

新しい空のNotebookを作り、タイトル・氏名・問いをMarkdownで書く。必要なデータを同じフォルダへ保存。コードを実行し、結果と自分の説明を交互に置く。前の週の提出がなくてもスターターから始められる。Create a blank notebook; write title, name and question in Markdown. Save needed data beside it. Alternate code/results with your explanation. The starter works without a previous submission.

30分のチャレンジ30-minute challenge

  • 二つの予算（事件課題は二つの集計列）で使い、違いを説明する。Run two budgets, or two grouping columns for incident data, and explain the difference.
  • 候補0件・対象0行でも、読み手に伝わる結果を出す。Give an understandable result when no options or records match.
  • 一つの処理を関数にし、相手に試してもらって一か所直す。Put one operation in a function; improve one issue found by a partner.

保存するものSave your evidence

予想→変更→結果→確認。各セルの役割をMarkdownで説明し、全セルを実行して出力を保存する。派手さより、自分で説明できる変更を大切に。Prediction → change → result → check. Explain steps in Markdown, run all cells and save outputs. Choose a change you can explain.
