Notebook用。4種類のスポークを4周、0.15秒ずつ表示。clear_outputは前の出力を消す、time.sleepは少し待つ。数字や文字を変えてみよう。For notebooks: show four spoke positions four times, 0.15 seconds each. clear_output replaces the previous frame; time.sleep pauses briefly. Try changing the numbers and characters.

Python
# アニメーションの回数と速さを先に設定する
turns = 4
pause = 0.15
wheels = ["-", "\\", "|", "/"]

# Notebookの出力を入れ替える道具。pandasは不要
import time
from IPython.display import clear_output

# 4種類の車輪を順番に表示する。有限回なので自動で止まる
for spoke in wheels * turns:
    clear_output(wait=True)
    print(r"    __o")
    print(r"  _ \<_")
    print(f" ({spoke})/({spoke})")
    time.sleep(pause)
