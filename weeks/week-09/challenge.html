その関数で、何ができる？What will your function do?

自分で選んだデータを使っても、データなしで小さなツールや遊びを作ってもOK。役に立つ、意外な発見がある、思わず笑える。関数で「何かができる」Notebookを作ろう。Choose a dataset, or build a small tool or game with your own inputs. Use a function to make a notebook that does something useful, surprising, or funny.

空のNotebookで始めよう。まず「どんな入力から、どんな結果を出したいか」を一文で書く。Start with a blank notebook and write one sentence about what goes in and what should come out.

宿題・提出Homework and submission

最低要件Minimum requirements

  • 処理を2段階。 def で入力を受け取り、関数の中で if または for を使って、絞り込み→集計、計算→判定などの処理を行い、return で結果を返す。Two processing steps. Write a function that accepts input, uses if or for inside it, and returns a result. For example, filter then count, or calculate then make a decision.
  • 入力を3通り。 普通の入力、別の結果になる入力、境目や該当なしのケースで実行し、結果を残す。Three test cases. Run the function with a typical input, one that produces a different result, and a boundary case or a case with no matches. Save all three results.
  • 結果を使う。 返り値を使って、表・グラフ・提案・ゲームの判定など、意味のある結果を表示する。文字だけでもOK。Use the return value. Show a meaningful result: a table, chart, recommendation, or game outcome. Plain text is fine.
  • Markdownで説明。 タイトル・氏名に加え、誰のために何をするのか、入力を変えると結果がどう変わるのかを短く書く。Explain it in Markdown. Include your title and name, what the notebook does and for whom, and how changing the input changed the result.

あいさつに名前を入れるだけ、あるいは授業の例をそのまま写すだけでは要件を満たしません。A greeting with a different name or an unchanged classroom example does not meet the requirements.

最低要件を満たす例Examples that meet the minimum

  • 自転車盗： 市名で記録を絞り、件数を返す。2つの市と該当なしを試し、件数を表示する。Bike theft: Filter reports by city and return the count. Show the counts for two cities and a no-match case.
  • 休み時間： 残り時間から往復の移動時間を引き、5分以上残るかで提案を変える。余裕あり・時間不足・ちょうど5分を試す。Break planner: Subtract round-trip walking time from the break length. Change the suggestion depending on whether at least five minutes remain. Test plenty of time, too little time, and exactly five minutes.

発展アイデア（任意）Stretch ideas (optional)

  • 絞り込みから地図へ： 地震を規模・深さで絞る関数と、結果を地図や散布図にする関数を分ける。条件を変えた2枚を比べる。Filter, then plot: Use one function to select earthquakes by magnitude and depth and another to map or plot the results. Compare two sets of criteria.
  • ランキング： 選んだ地域の65歳以上の割合を for で計算し、順位順に並べたリストを返す関数を作る。その結果を棒グラフにする。Rank regions: Write a function that loops over selected regions, calculates each region’s share aged 65+, and returns a sorted list. Turn the list into a bar chart.
  • ミニゲーム： 1回分の勝敗を判定し、得点を更新して返す関数を作る。while で繰り返し遊べるようにし、引き分けや無効な入力も試す。Mini-game: Write a function that decides the outcome of a round and returns the updated score. Use while to replay, and test draws and invalid input.

API・pandas・グラフ用ライブラリは必須ではありません。No API, pandas, or charting library is required.
