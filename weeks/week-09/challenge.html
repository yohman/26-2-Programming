その関数で、何ができる？What will your function do?

自分で選んだデータを使っても、データなしで小さなツールや遊びを作ってもOK。役に立つ、意外な発見がある、思わず笑える。関数で「何かができる」Notebookを作ろう。Choose a dataset, or build a small tool or game with your own inputs. Use a function to make a notebook that does something useful, surprising, or funny.

Notebookに入れるものWhat to put in your notebook

  • 空のNotebookを作り、タイトル・氏名・「誰のために何をするか」をMarkdownに書く。Start a blank notebook. In Markdown, add your title, name, and what the notebook does for whom.
  • def で入力を受け取り、return で結果を返す関数を一つ作る。Write at least one function with def that takes an input and uses return to give back a result.
  • 同じ関数を違う入力で2回試して、結果を保存する。何件も処理するときは for から呼んでみよう。Call the same function with two different inputs and save the results. If you have many items, try calling it from a for loop.

例えばFor example

  • 自転車盗データと市名を渡して、その市の記録件数を返す。Give your function the bike data and a city name; get back the city’s reported theft count.
  • 都市名を渡して、天気と最高・最低気温のバッジを返す。Give your function a city name; get back a badge with the weather and temperatures.
  • 残り時間を渡して、休み時間にできることを提案する。Give your function the minutes left in your break; get back a suggestion for what to do.

見本は天気で実演しています。APIやpandasは必須ではありません。The worked notebook uses weather as an example. No API or pandas is required.
