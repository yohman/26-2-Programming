greetを作るDefine greet

Python
def greet():
    return "Hello!"

1行目：def で定義。: の次の行は右にずらす。2行目：return で結果を返す。Line 1: def starts the definition. After the colon, indent the next line. Line 2: return gives back a result.

ここで何が表示される？What appears if we run just this?

まだ何も表示されません。次のスライドで呼び出します。Nothing yet. We call it on the next slide.

かっこの中に、名前を一つOne name inside the parentheses

Python
def greet_name(name):
    return f"Hello, {name}!"

greet_name("Haru")
'Hello, Haru!'

"Haru" が name に入る。"Yui" に変えたら、何が返る？"Haru" goes into name. What comes back if you change it to "Yui"?

3人なら、3回呼ぶThree names, three calls

Python
names = ["Haru", "Yui", "Ren"]

for student in names:
    message = greet_name(student)
    print(message)
—

    for が次の名前を選ぶ。greet_name があいさつを返し、次の行で表示する。for picks the next name. greet_name returns a greeting, and the next line displays it.

    名前を、都市と天気にA label for one city

    Python
    def weather_label(city, icon, high, low):
    return f"{icon} {city}\n↑{high}°C  ↓{low}°C"

print(weather_label("柏", "☁️", 16.6, 6.1))
    ☁️ 柏
↑16.6°C  ↓6.1°C

    入力は4つ。順番を変えたら、何がどこに表示される？ ↑は最高、↓は最低。There are four inputs. What happens if you swap their order? ↑ is the daily high; ↓ is the low.

    2026-11-12 · Open-Meteo2026-11-12 · Open-Meteo

    文字列を、1枚のバッジにOne label becomes one badge

    Python
    from html import escape

def weather_badge(city, icon, high, low):
    label = weather_label(city, icon, high, low)
    safe_label = escape(label)
    style = ("padding:.75rem;background:#e8eff3;"
             "border-top:3px solid #315876;white-space:pre-line")
    return f'<div style="{style}">{safe_label}</div>'
    ☁️ 柏 ↑16.6°C ↓6.1°C

    中で weather_label を呼び、見た目を付けてHTMLを返す。HTMLはここでは表示用。escapeは文字を安全に表示するため。The function calls weather_label, adds styling and returns HTML for display. escape keeps the label as text.

    関数の中で、forが回るA loop inside the panel function

    Python
    def weather_panel(cities, forecast):
    badges = []
    for city in cities:
        icon, high, low = forecast[city]
        badges.append(weather_badge(city, icon, high, low))

    style = "display:grid;grid-template-columns:repeat(2,1fr);gap:8px"
    return f'<div style="{style}">{"".join(badges)}</div>'
    表示する都市Cities to show

    都市を選んで予想しよう。appendで1枚ずつ追加し、ループが終わってからパネル全体をreturnする。Select cities and predict the count. append adds one badge at a time. After the loop, return sends back the whole panel.

    保存済みのPython出力を使ったシミュレーション。Notebookではdisplay(HTML(...))で表示。Browser simulation uses saved Python output. In the notebook, display(HTML(...)) renders the panel.
