    同じ関数で、3市の棒グラフThree cities, one bar function

counts = {'柏市': 564, '松戸市': 725, '船橋市': 1299}

    65歳以上は、何％？How much of each prefecture is 65+?

    Python
    # japan.csvから4都県の65歳以上人口と総人口
prefectures = {
    "千葉県": {'65+': 1753000, 'total': 6266000},

shares = {}

    文字列を、1枚のバッジにOne label becomes one badge

    Python
    # HTML表示に使う escape と柏の天気
from html import escape

city = "柏"
icon, high, low = ('☁️', 16.6, 6.1)

# ラベルを作り、バッジ用のHTMLにする
def weather_label(city, icon, high, low):

def weather_badge(city, icon, high, low):

    関数の中で、forが回るA loop inside the panel function

    Python
    # HTML表示に使う escape と4都市分の天気
from html import escape

forecast = {'柏': ('☁️', 16.6, 6.1),
 '札幌': ('☁️', 10.8, -0.1),
 '大阪': ('☁️', 18.2, 7.2),
 '那覇': ('🌦️', 25.9, 21.1)}

cities = ["柏", "札幌", "大阪", "那覇"]

# ラベル、バッジ、パネルを作る関数
def weather_label(city, icon, high, low):
    return f"{icon} {city}\n↑{high}°C  ↓{low}°C"

def weather_badge(city, icon, high, low):
    label = weather_label(city, icon, high, low)
    safe_label = escape(label)
    style = ("padding:.75rem;background:#e8eff3;"
             "border-top:3px solid #315876;white-space:pre-line")
    return f'<div style="{style}">{safe_label}</div>'

def weather_panel(cities, forecast):
    badges = []
    for city in cities:
        icon, high, low = forecast[city]
        badge = weather_badge(city, icon, high, low)
        badges.append(badge)

    style = "display:grid;grid-template-columns:repeat(2,1fr);gap:8px"
    return f'<div style="{style}">{"".join(badges)}</div>'

# 関数を呼び出す
panel = weather_panel(cities, forecast)
    表示する都市Cities to show

    都市を選んで予想しよう。appendで1枚ずつ追加し、ループが終わってからパネル全体をreturnする。Select cities and predict the count. append adds one badge at a time. After the loop, return sends back the whole panel.

    保存済みのPython出力を使ったシミュレーション。Notebookではdisplay(HTML(...))で表示。Browser simulation uses saved Python output. In the notebook, display(HTML(...)) renders the panel.
