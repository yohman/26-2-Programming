spinner.py

|

Python
from time import sleep

symbols = ["|", "/", "-", "\\"]

# 4つの記号を3周。1コマずつ同じ場所に上書きする
for symbol in symbols * 3:
    print("\r" + symbol, end="", flush=True)
    sleep(0.2)

print()

symbols * 3 で4つの記号を3周。\r で行の先頭に戻り、次の記号で上書きする。end="" は改行なし、flush=True は待つ前に表示。最後の print() だけが改行する。symbols * 3 cycles through the list three times. \r returns to the start of the line so the next symbol replaces the last one. end="" skips the newline. flush=True shows the symbol before the pause. The final print() adds a newline.

from time import sleep で待つ関数を使える。sleep(0.2) はループの中で、表示するたびに0.2秒（200ミリ秒）待つ。0.8秒にすると、絵もコマ数も同じまま、動きが遅くなる。from time import sleep brings in the pause function. Inside the loop, sleep(0.2) waits 0.2 seconds (200 ms) after each print. At 0.8 seconds the frames stay the same, but the animation is slower.

from time import sleep

# 空白の数で、列車の位置を変える
def train_frame(position):
    return " " * position + "[==][==][__]>o"


# 1コマずつ同じ行に描き直す。steps はコマ数、delay は待ち時間（秒）
def animate_train(steps, delay):
    for position in range(steps):
        print("\r" + train_frame(position), end="", flush=True)
        sleep(delay)

    # 終わったら改行してターミナルの入力欄に戻る
    print()


animate_train(18, 0.12)

train_frame() は絵を1コマ返す。animate_train() はループで表示し、sleep(delay) で待つ。\r と end="" で同じ行に上書きし、flush=True ですぐに表示する。train_frame() returns one drawing. animate_train() loops, displays each drawing, and waits at sleep(delay). \r and end="" reuse the same line; flush=True shows it immediately.

from time import sleep


# 停留所のリストと、今いる停留所の番号を受け取る
def route_frame(stops, current):
    rows = ["CAMPUS SHUTTLE"]
    for i in range(len(stops)):
        marker = "  "
        if i == current:
            marker = "> "
        rows.append(marker + stops[i])
    return "\n".join(rows)


stops = ["Campus", "Library", "Station"]

# 描き直すたびに、次の停留所へ
for current in range(len(stops)):
    print("\033[2J\033[H" + route_frame(stops, current), flush=True)
    sleep(0.65)

stops は停留所のリスト。外側の for で次の停留所へ。関数内の if が、いまの停留所にだけ > を付ける。リストに「Cafeteria」を足すと？stops is a list. The outer for moves to the next stop; the if inside the function marks only the current one with >. What happens if you add “Cafeteria” to the list?

DOT    .

from time import sleep

spinner = ["|", "/", "-", "\\"]
faces = ["🙂", "😮"]


def tiny_frame(step):
    # % は余り。0〜3、0〜1を繰り返す
    spin = spinner[step % 4]
    face = faces[step % 2]
    dot = " " * step + "."
    return f"SPIN   {spin}\nDOT    {dot}\nEMOJI  {face}"


for step in range(12):
    print("\033[2J\033[H" + tiny_frame(step), flush=True)
    sleep(0.2)

スピナーは | / - \ を順番に出す。ドットは空白の数、絵文字はリストの何番目を選ぶかで変わる。絵文字はASCIIではなく、端末によって幅が違うことがある。The spinner cycles through | / - \. Spaces move the dot, and a list supplies the faces. Emoji are Unicode and may take up different widths in different terminals.

from time import sleep

# 固定の屋根に、雨の行を2行足す
def rain_frame(drops):
    return (
        drops + "\n" + "  " + drops + "\n"
        "        /\\\n"
        "    ___/  \\___\n"
        "      | [] |\n"
        "______|____|______"
    )


# 雨の模様を順番に切り替える
rain = [" .   .    .  .", "  /   /  /   /", "   .   .  .   ."]
for repeat in range(3):
    for drops in rain:
        # 画面を消してから、次のコマを描く
        print("\033[2J\033[H" + rain_frame(drops), flush=True)
        sleep(0.28)

雨の行だけを変えて、屋根は固定。\033[2J\033[H はターミナルを消去して左上に戻す合図。複数行を描き直したいときだけ使う。Change the rain while the roof stays still. \033[2J\033[H clears the terminal and moves the cursor to the top left. Use it only when you want to redraw several lines.

Python
# 数字は、ビルの高さ
heights = [2, 5, 3, 6, 4, 2]


def skyline_row(level):
    row = ""
    for height in heights:
        if height >= level:
            row += "[#] "
        else:
            row += "    "
    return row.rstrip()


# 高いところから1段ずつ描く
for level in range(max(heights), 0, -1):
    print(skyline_row(level))
print("=" * (4 * len(heights)))

level は今描く段。ループは各ビルの高さを調べ、届くなら [#]、届かないなら空白にする。level is the row being drawn. For each building, the loop adds [#] if the building reaches that level, or spaces if it doesn’t.

from time import sleep

lights = ["STOP", "GO", "WAIT"]


def signal_frame(active):
    rows = ["+----------+"]
    for light in lights:
        # 今の状態にだけ星印をつける
        mark = "*" if light == active else "."
        rows.append(f"| ({mark}) {light:<4} |")
    rows.append("+----------+")
    return "\n".join(rows)


for active in ["STOP", "GO", "WAIT", "STOP"]:
    print("\033[2J\033[H" + signal_frame(active), flush=True)
    sleep(0.65)

位置は変えず、active と同じ行だけに * を表示する。リストの順番を変えると、何が変わる？Nothing moves across the screen. Only the row that matches active gets a *. What happens if you change the order of the states?

Python
from time import sleep

sky = [
    "  *                    .   ",
    "        .                * ",
    " *                 .       ",
    "          .                ",
    "    .                   *  ",
    "                     .     ",
    "  .                        ",
    "        .               .  ",
    "                           ",
    "                           ",
    "                           ",
    "                           ",
]
rocket = [
    "   ^   ",
    "  / \\  ",
    "  |o|  ",
    " /___\\ ",
    "   *   ",
]
# すべての行を同じ幅にして、空の中央に置く
x = (len(sky[0]) - len(rocket[0])) // 2
launch_row = len(sky) - len(rocket)


def flight_frame(top, message):
    title = message.center(len(sky[0]))
    rows = [title.rstrip()]
    for y in range(len(sky)):
        line = sky[y]
        # ロケットの先端から何行下か
        part = y - top
        if 0 <= part < len(rocket):
            piece = rocket[part]
            end = x + len(piece)
            line = line[:x] + piece + line[end:]
        rows.append(line.rstrip())
    rows.append("-------- LAUNCH PAD -------")
    return "\n".join(rows)


for step in range(10):
    # 上に行くほど、先端の行番号は小さい
    top = max(0, launch_row - step)
    if step == 0:
        message = "READY"
    elif top == 0:
        message = "ORBIT REACHED"
    else:
        message = "LIFTOFF"
    print("\033[2J\033[H" + flight_frame(top, message), flush=True)
    sleep(0.35)

外側の for step が時間を進める。flight_frame の中の for y は一コマを上から1行ずつ描き、必要な行にだけロケットを重ねる。The outer for step advances time. Inside flight_frame, for y builds one frame top to bottom and overlays the rocket only on the rows it occupies.

20分：作品を作る20 minutes: Build your piece

たとえば、終電の発車案内、3秒で変身するキャラクター、1軒だけ明かりがつく夜の街。テーマは自由。サンプルを使うなら文字を置き換えるだけでなく、変化のルールを一つ変える。Try a last-train departure board, a character that transforms on cue, or a skyline with one lit window. Your own idea is welcome. If you start from an example, change a rule that controls what we see.

  • 入力を受け取って1フレーム（または1行）の文字列を返す関数を作る。Write a function that takes an argument and returns the text for one frame or row.
  • for ループで違う値を関数に渡し、位置・形・文字などを変えて表示する。Call it in a for loop with different values so the position, shape, or text changes.
  • 見どころを一つ作る。動画なら登場・点灯・到着など。静止画なら模様や形が切り替わる場所を作る。Give the audience one moment to notice: a character arrives, a sign lights up, or a still picture changes pattern at a chosen row.
  • ターミナルで実行できて、自然に終了することを確かめる。追加パッケージは不要。Check that it runs in a terminal and ends on its own. No extra packages are needed.

新しい ascii.py を作る。まず関数で1コマを描き、次に2つの引数で呼び出して違いを確認。最後にループでつなげて、ターミナルから実行する。Create a new ascii.py. Make one frame with a function, then call it with two different values and check what changes. Finally, connect the frames in a loop and run the script from the terminal.

発展：背景と動くものを別々の関数で作る。位置が端に着いたら、台詞や次の場面を切り替える。Stretch: draw the background and moving object in separate functions, or switch the caption or scene when the object reaches an edge.
