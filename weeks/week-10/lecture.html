Terminalで実行Run it in a terminal

VS CodeのTerminal→New Terminal。ファイルのフォルダを開き、次のコマンドを入力する。>>>はPython対話画面で、Terminalのプロンプトとは違う。Open Terminal → New Terminal in the file’s folder. A >>> prompt is the Python interpreter, not the shell.

# macOS
python3 hello.py

# Windows Python launcher
py hello.py

Windowsでpyがなければ、選択したPythonに対応するpython hello.pyを使う。VS CodeのRun Python Fileでも実行できる。If py is unavailable, use python hello.py with your selected installation, or VS Code’s Run Python File.

WEEK 10 · Python outside the notebook

自分の関数を呼ぶCall your function

定義が先、呼び出しが後。Notebookの実行順に頼らず、ファイルを最初から実行する。Define before calling; the script starts fresh rather than relying on notebook state.

Python
def remaining(budget, price):
    balance = budget - price
    return balance

print(remaining(1000, 470))

WEEK 10 · Python outside the notebook

入力は文字列input returns text

input()は文字列を返す。int()で整数へ。数字以外が来たら、短い案内を出す。input() returns text; int() converts it. Explain invalid input instead of a confusing crash.

try:
    budget = int(input("Budget in yen: "))
    print(remaining(budget, 470))
except ValueError:
    print("Enter a whole number, such as 1000.")

__name__の小さな役割The __main__ guard

if __name__ == "__main__": の内側は、直接実行したときだけ動く。importしただけでinputが始まるのを防ぐ。The __main__ guard runs interactive code only on direct execution, so import does not unexpectedly ask for input.
