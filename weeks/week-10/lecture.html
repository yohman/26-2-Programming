from time import sleep

# 空白の数で、列車の位置を変える
def train_frame(position):
    return " " * position + "[==][==][__]>o"


# 1コマずつ同じ行に描き直す
for position in range(0, 18):
    print("\r" + train_frame(position), end="", flush=True)
    sleep(0.12)

# 最後に改行して、プロンプトと絵を分ける
print()

\r は行の先頭へ戻る。end="" で改行せず、flush=True で今すぐ表示。sleep(0.12) は次のコマまでの待ち時間（秒）。\r returns to the start of the line. end="" skips the newline and flush=True displays immediately. sleep(0.12) waits 0.12 seconds.

動いているプログラムを止めるには Ctrl+C。Press Ctrl+C in the terminal to stop a running script.

from time import sleep

# 固定の屋根に、雨の行を2行足す
def rain_frame(drops):
    return (
        drops + "\n" + "  " + drops + "\n"
        "        /\\\n"
        "    ___/  \\___\n"
        "      | [] |\n"
        "______|____|______"
    )


# 雨の模様を順番に切り替える
rain = [" .   .    .  .", "  /   /  /   /", "   .   .  .   ."]
for repeat in range(3):
    for drops in rain:
        # 画面を消してから、次のコマを描く
        print("\033[2J\033[H" + rain_frame(drops), flush=True)
        sleep(0.28)

雨の行だけを変えて、屋根は固定。\033[2J\033[H はターミナルを消去して左上に戻す合図。複数行を描き直したいときだけ使う。Change the rain while the roof stays still. \033[2J\033[H clears the terminal and moves the cursor to the top left. Use it only when you want to redraw several lines.

30分：ASCIIチャレンジ30 minutes: ASCII challenge

文字だけで、自分のシーンを作ろう。動く作品でも、ループで行を増やす一枚絵でもOK。Make an original scene out of text. Animate it, or use a loop to build a still picture one row at a time.

  • 入力を受け取って1フレーム（または1行）の文字列を返す関数を作る。Write a function that takes an argument and returns the text for one frame or row.
  • for ループで違う値を関数に渡し、位置・形・文字などを変えて表示する。Call it in a for loop with different values so the position, shape, or text changes.
  • ターミナルで実行できて、自然に終了することを確かめる。追加パッケージは不要。Check that it runs in a terminal and ends on its own. No extra packages are needed.

たとえば、柏駅の発車案内、点滅するゲームのタイトル、行ごとに模様が変わるポスター。自分のアイデアも歓迎。Try a Kashiwa Station departure board, a blinking game title, or a poster that changes pattern row by row. Your own idea is welcome.
