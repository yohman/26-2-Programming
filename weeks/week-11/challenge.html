検出器は、何を見落とした？What did the detector miss?

検出された顔の枠を描き、見落とし・誤検出を人の目で確認する。OpenCVが動かなくても、配布した実際の検出座標CSVを使って同じループを実行できる。Draw face-detection boxes and inspect misses and false positives. If OpenCV is unavailable, process the supplied real detection-coordinate CSV with the same loop.

30分のチャレンジ30-minute challenge

  • 入力画像・座標・検出件数の関係を説明する。Explain how the input image, boxes and detection count relate.
  • 枠の色・太さ・大きさ条件など、一つを変えて結果を確認する。Change one property such as box color, width or size filter and check the result.
  • 見落としか誤検出を一つ記録し、何が言えないかを書く。Record one miss or false positive, and one conclusion the output cannot support.
