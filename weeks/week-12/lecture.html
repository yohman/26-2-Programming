WEEK 12 · One click, one function

クリック一回で、関数一回One click calls one function

hitは状態を受け取り、次の得点を返す。0秒なら増えない。hit receives state and returns the next score; no points at zero seconds.

Python
def hit(score, seconds_left):
    if seconds_left > 0:
        return score + 1
    return score

print(hit(0, 3))
print(hit(1, 0))

WEEK 12 · One click, one function

command=hit と hit()command=hit versus hit()

command=hitは「押されたら呼ぶ関数」を渡す。command=hit()は今呼んでしまう。配布GUIは引数なしのon_hitを使う。global scoreは外側の得点を書き換える宣言。中心のhitは値を返すだけ。command=hit supplies a callback; command=hit() calls it immediately. The GUI uses the no-argument on_hit wrapper. global score lets that wrapper update module-level state; the core hit function only returns a value.

WEEK 12 · One click, one function

while Trueで画面を止めないDo not freeze the event loop

GUIには入力を待つイベントループがある。root.after(1000, tick)で、1秒後にtickを呼ぶよう予約する。A GUI already has an event loop. root.after(1000, tick) schedules tick for one second later.

Python
def tick():
    global seconds_left
    seconds_left -= 1
    if seconds_left > 0:
        root.after(1000, tick)
